# Патч Корпус Терна 0.11.2 — установка и пределы проверки

**Это пакет исходников для GitHub, а НЕ готовая папка Mods.** Базовый коммит — `6550d995ae1417e6f4af470aaf8b47ac0cbd1478` (последняя успешная 0.11.1).

1. Распакуйте ВСЁ содержимое в корень локального репозитория `ThornWhip` через Github Desktop → Repository → Show in Explorer. Применяйте замену.
2. Summary: `Fix CE runtime definitions and rebalance Thorn Corps 0.11.2`.
3. Commit to main → Push origin.
4. GitHub → Actions → успешная сборка 0.11.2 → внизу Artifacts `ThornCorps-CE-0.11.2-TEST`. Скачайте ZIP, внутри ещё установочный ZIP `ThornCorps_CE_0.11.2_INSTALL.zip`.
5. Удалите предыдущую RimWorld/Mods/ThornWhip, распакуйте внутренний установочный ZIP в RimWorld/Mods/.

Версия 0.11.2 содержит реальные изменения сохранения баланса, материальных оснований переплавки и бронебойности HEAT, НЕ просто отключение игрового журнала. Она основана на исследовании исходников CE, а **не на прогоне игры**. Все 6 локальных статических тестов прошли, компиляцию ещё должен выполнить GitHub. Живую загрузку CE и боевые эксперименты можно подтвердить только по новому Player.log.

Не используйте старые тестовые сохранения: суффиксы дефиниций были изменены в 0.11.1; миграция пока не разработана.
