# Корпус Терна v0.10 — настоящие игровые текстуры (исходный проект)

**СТАТУС: графические ресурсы интегрированы в файлы мода; C# DLL всё ещё отсутствует.**
Этот архив НЕ является готовым установочным релизом для `Mods`. Статические тесты проверяют только PNG/XML, не работу в игре.

## Что заменено

- Четыре семейства оружия: 64 цельных текстуры для технических конфигураций (32 × 2 палитры); слои для каждого шасси, 15 узлов × 5 вариантов и 15 общих дополнительных модификаций для каждого семейства, обе цветовые схемы.
- Девять броневых основ (лёгкая/средняя/тяжёлая × Т1–Т3): предметы, четыре направления надетой брони, слои конструктора и два цветовых оформления.
- Семь семейств турелей (21 игровой ThingDef): новые нарисованные сверху корпуса, по четыре файла направления каждого варианта и два цветовых оформления.
- Стены, амбразуры, окопы, три глубины рва, ворота, огневые позиции и оба производственных верстака: реальная графика `Graphic_Multi` с `_north`, `_east`, `_south`, `_west`.
- Созданы `StyleCategoryDef` «Корпус Терна» и «Орден Терна» и связанные `ThingStyleDef` для поддерживаемых предметов и зданий, с `CompProperties_Styleable`.

## Разница палитр

- **Корпус Терна:** угольно-чёрный графит, воронёная сталь, красные бронеплиты, красная световая индикация.
- **Орден Терна:** светлая керамическая бронесталь, белые поверхности, красные плиты и маркировка, тёмные швы и металлические каналы.
- Земля и вода в окопах/рвах сохраняют свой естественный цвет. Их металлические обрамления подчиняются выбранному стилю.

## Принцип поворота

`ThingDef.graphicData.graphicClass = Graphic_Multi`, `rotatable=true` для конструкций с направленной геометрией.
Файлы располагаются по стандартным путям `X_north.png`, `X_east.png`, `X_south.png`, `X_west.png`.
У турелей реальная динамическая отрисовка вращающейся головы Combat Extended **ещё не проверена**: в игре возможно наложение спрайта поворотной части и штатного CE-механизма, которое потребует корректировки.

## Важно для модульной графики

Модульные слои настоящие PNG в `Textures/ThornWhip/Parts/...` и их белые варианты в `Textures/ThornCorps/StyleOrder/ThornWhip/Parts/...`.
Слой конструктора рисуется в интерфейсе по выбранным деталям. **При выборе белого стиля базовый ThingStyleDef ссылается на белую текстуру, но специальная отрисовка отдельных модулей в руках/на земле пока не определяет стиль автоматически.** Исправление требует C#-проверки и компиляции. На пешках броня показывает базовое надетое шасси, не все индивидуальные конструктивные модули.

## Проверка

`python tests_static_09.py` — сохранность исходных игровых определений.
`python tests_visuals_10.py` — PNG, XML, стильные ссылки, направления, полнота модульных изображений.

## Сборка

`build_linux.sh` или `build_windows.ps1` используют `dotnet` и `net10.0`, как и проект v0.9. В GitHub Actions добавлены визуальные проверки и упаковка v0.10.
Для воспроизведения нового набора текстур используется `python upgrade_visual_assets_10.py` и **все исходные файлы**, включённые в `Showcase/Input_1_0`; старые скрипты генерации графики v0.5–0.9 не запускать поверх подготовленных PNG.

# КОРПУС ТЕРНА · SOURCE 0.9.0

**RimWorld 1.7, Combat Extended, Odyssey (орбита).** Продолжение версии 0.8: всё прежнее оружие, девять бронебаз, система чертежей, фракция и заводы-крепости остались. Весь проект называется **«Корпус Терна»**, а **«Плеть Терна»** — название одной винтовки.

Архив включает исходники и ресурсы **семи платформ турелей** и фортификаций; **DLL отсутствует**, поэтому напрямую в папку Mods ставить эту версию **нельзя**. Не проверены компиляция, CE 1.7 и игровая работа (это не установочный ZIP).

Основные новые файлы:

- `ThornWhip/Defs/TC_Turrets.xml` — 21 башня со своими CE орудийными механизмами.
- `ThornWhip/Defs/TC_TurretGuns.xml` — 21 CE gun Def.
- `ThornWhip/Defs/TC_EnergyAmmo.xml`, `TC_RocketAmmo.xml`, `TC_RailAmmo.xml` — энергетические и ракетные боеприпасы, новый 30-мм сердечник.
- `ThornWhip/Defs/TC_Fortifications.xml` — амбразуры, стены, бастионы, окопы, рвы.
- `ThornWhip/Defs/TC_DefenseJobs.xml` — строительные работы и доставка.
- `ThornWhip/Source/TurretRetrofits.cs` — права установки, универсальный оружейный держатель, проект модернизации, доставки материалов и отключение стрельбы.
- `ThornWhip/Source/ThornMoats.cs` — гидрологический пересчёт связных рвов.
- `ThornWhip/Source/ThornFortresses.cs` — включение укреплений в наземные и орбитальные поселения Корпуса.
- `ThornWhip/Textures/ThornCorps/Defense` — реальные игровые PNG-спрайты.
- `Showcase/THORNCORPS_DEFENSE_0.9.png` — обзор игровых спрайтов.
- `ThornWhip/Documentation/DEFENSE_SYSTEM_RU.md` — **точные сведения о готовом и неготовом**.

## Компиляция после загрузки проекта в GitHub

Содержимое этого ZIP загрузить в корень репозитория вместо исходников 0.8 (сохраняя папку `.github`). GitHub Actions запускает `tests_static_09.py`, затем компиляцию .NET 10 и создание `ThornCorps_CE_Constructor_0.9_INSTALL.zip` **только в случае успешной сборки**. Сценарии сборки есть для Linux/Windows. До исправления ошибок компиляции и игрового smoke-test не считать релиз готовым.

## Фактически выполненные проверки

Статические проверки XML и связей Def, сохранение старых каталогов, изображения, структура CI. Они не имитируют поведение RimWorld или CE.

**Особенно важно:** из-за ограничений отсутствующей игровой среды пока **не реализованы непрерывный гарантированно попадающий лазерный луч и проверенная универсальная совместимость держателя с любым носимым оружием**. Для модернизации подготовлена C#-логика заказов, но её работоспособность ещё требуется подтвердить сборкой и тестами. Подробнее в документации оборонительной системы.
