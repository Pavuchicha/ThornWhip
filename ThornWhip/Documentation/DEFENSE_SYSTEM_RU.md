# КОРПУС ТЕРНА / 0.9 / ТУРЕЛИ И ФОРТИФИКАЦИИ

> Статус: **исходный проект, без скомпилированной DLL и без тестирования в RimWorld 1.7 + CE**.
> В таблицах указаны значения XML, не доказанные игровые результаты.

## Семь боевых платформ

| Платформа | CE-реализация / тип снаряда | Варианты для выбора после постройки | Назначение |
|---|---|---|---|
| Универсальный держатель | Специальная рама и экспериментальный отражательный CE-адаптер для `ThingWithComps` | пустая базовая станина; установка личного оружия | малый гарнизонный огневой пункт |
| Роторный миниган | CE `Verb_ShootCE`, 5.56 / 7.62 / 20 мм | 4, 6, 8 стволов; усиленный калибр | подавление и защита ближнего–среднего периметра |
| Лазер | новые `TC_AmmoSet_Laser` и конденсаторные батареи | фокус, охлаждение, импульсный пакет | одна цель; защита слабо бронированных |
| Бластер | новый `TC_AmmoSet_Blaster`, энергетические болты | рассеивание, бронебой, скоростной пакет | очереди энергоснарядов, среднее пробитие |
| Рейлган | 7,62×51 CE, 20×128 CE, отдельный 30-мм сердечник CE | лёгкий 2×2, средний 3×3, тяжёлый 4×4 | дальнобойный прицельный огонь |
| Автоматическая ПТУР | `TC_AmmoSet_ATGM` с HEAT и HE, по одной ракете | одноствольный, двойной, улучшенное сопровождение | бронецели и стационарные укрепления |
| РСЗО | `TC_AmmoSet_MLRS`, HE ракетная кассета | 6, 12, 9 ракет в залпе | площадной огонь, слабая эффективность против брони |

**Не путать профили с независимой модульной системой.** В версии 0.9 у турелей сохраняется перечень готовых CE-профилей *орудийных механизмов*, чтобы характеристики конкретного AmmoSet и выпускаемого снаряда не приходилось динамически менять у глобального ThingDef во время игры. По мере подтверждения API профильные варианты должны дополняться независимыми вторичными модульными слотами. Профиль меняет спрайт (для всех, где есть второй профиль).

### CE / достоверность

- Для обычных патронов используются типы CE, а для новых энергетических и ракетных систем определены отдельные `AmmoSetDef`, `AmmoDef`, `ProjectilePropertiesCE`, рецепты и категории.
- При любой стрельбе по существующему пути Combat Extended огонь, боеприпасы и броня рассчитываются CE. **Не добавлен** собственный глобальный тик для вычисления баллистики.
- Лазерные профили пока имеют **очень малый угловой разброс**, но **не обеспечивают строго 100% попадания и не создают непрерывный безразрывный луч**; пока это CE-энергоболты. Для точного выполнения нужна отдельная проверенная CE-реализация hitscan/beam-verb, интегрированная в потребление боеприпасов. Это открытый пункт.
- ПТУР использует классы CE, но реального управляемого наведения и проверки модели HEAT на движущемся объекте нет. `Guided` — уточнённый низкий разброс, а не доказанное самонаведение.
- Рейлган стреляет CE снарядами; отдельная электромагнитная модель энергии запуска пока не вносит физических изменений в расчёт CE-полёта.
- РСЗО имеет низкую кучность, высокую плотность очереди и дистанционную мёртвую зону. Действительный фугасный баланс требуется измерить.

## Строительная модернизация

При выборе турели открывается действие **«Модифицировать турель»** (также есть пункт ПКМ бойцом). Можно выбрать другой профиль того же семейства.

1. `CompThornTurret.Request` фиксирует новую сборку в сохранении.
2. CE-турель блокируется узким Harmony-гейтом перед новой очередью, пока модернизация не окончена.
3. Строители через отдельный `WorkGiver_ThornRetrofit` получают задания доставки недостающих ресурсов из хранилищ.
4. Материалы физически переносятся в `ThingOwner` установки и сохраняются в save.
5. Только после полной поставки строитель выполняет работу на турели. При завершении создаётся новое здание с нужным CE `turretGunDef`; старое здание убирается без перенастройки глобального Def.
6. По отмене материалы возвращаются на карту; при разрушении тоже предпринята попытка вернуть ресурсы и снятое оружие.
7. Для большой версии рейлгана проверяется свободное место до заказа и перед заменой.

**Не подтверждено в игре:** корректность JobDriver и переноса материалов на RimWorld 1.7, отсечка всех возможных цепочек продолжения уже начатой CE-очереди, перенос заряженных патронов во время замены и сохранение внутреннего CE `gun` при переходе между объектами.

### Универсальный держатель

Платформа строится без оружия. Боец с основным оружием может выбрать ПКМ по держателю и передать свой экземпляр оружия. Его ThingComp и качество сохраняются. Используется отражение поля CE для передачи `ThingWithComps` внутрь `Building_TurretGunCE`, а при отсутствии поддерживаемого поля станина остаётся выключенной. **Это экспериментальный адаптер: работоспособность с произвольным сторонним оружием не доказана и требует отдельного теста версии CE**. Нельзя считать эту платформу готовой к бою до успешного теста.

## Фортификации

- `TC_Fort_ReinforcedWall`: цельная бронестальная стена.
- `TC_Fort_Embrasure`: огневая амбразура с высотой `fillPercent=0.68`, `disableImpassableShotOverConfigError=true`, с расчётом CE по линии огня при загрузке.
- `TC_Fort_Bunker`: модульный бастион.
- `TC_Fort_Sandbag`: позиция низкого укрытия.
- `TC_Fort_Foxhole`: отдельный окоп для пешего стрелка.
- `TC_Fort_ArmoredGate`: укреплённая воротная секция (на 0.9 пока статическая преграда, **не действующая распашная дверь**).
- `TC_Trench_1/2/3`: три глубины рва. В сухом состоянии проходимы; вода при соединении с рекой/озером затапливает весь связный участок, при глубине 3 используется `WaterDeep` и соответствующая непроходимость.

### Вода и производительность

`MapComponent_ThornMoats` хранит только клетки рвов. При размещении или удалении рва его сеть становится грязной; не чаще одного раза в 2500 тиков сеть перебирается поиском в ширину `O(количество клеток рва)` с проверкой внешних соседних клеток воды. Вода, которую компонент сам нарисовал в другой клетке рва, не считается новым независимым источником. При пропадании источника предыдущий ландшафт восстанавливается, если он известен.

Не реализована динамическая визуализация течения, гидродавления, точной глубины в метрах, накопления и осушения по объёму. Не подтверждены все пути CE и Odyssey по обновлению pathfinding на `WaterDeep`.

## Графический стиль

Палитра: чёрная сталь, тёмный графит, красные бронепанели, холодные сенсорные огни, оранжевая маркировка опасности, тяжёлые крепления. Для семи основных платформ и 14 профильных вариантов отдельные топ-спрайты; 9 видов фортификационных элементов; уникальные изображения энергетических и ракетных боеприпасов. Это **настоящие PNG-ресурсы** для `texPath`, не только концепт-арт.

## Регрессии и проверка после первой сборки

1. Запустить 0.8 тесты вооружения, брони, фракции.
2. Запустить 0.9 тесты XML, семейства турелей, ресурсов и графики.
3. Пройти C# компиляцию через GitHub Actions (версия 0.9).
4. Запустить RimWorld с Harmony + подходящей версией CE 1.7 + «Корпус Терна», проверить отсутствие красных XML ошибок.
5. Проверить отдельными тестами: монтаж/демонтаж оружия, строительные заказы и расход ресурсов, нестрельбу при модификации, CE боеприпасы, отличия 3 размеров рейлгана, падение TPS при 10/30/100 турелях, затопление и непроходимость по воде, амбразуры со всех сторон.
6. Фактическую 100% меткость лазера и непрерывный луч создавать только после подтверждения CE-пути.
